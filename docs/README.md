# Documentation index

Where everything lives. Each folder has a README that says what belongs there and what is in it today.

| Folder | What goes here | Question it answers |
|---|---|---|
| [architecture/](architecture/README.md) | System context, components, data model, diagrams | How is it built? |
| [decisions/](decisions/README.md) | Architecture Decision Records (ADRs), one per significant decision | Why is it built this way? |
| [explanation/](explanation/README.md) | Background, concepts, research | Why does this exist and how should I think about it? |
| [governance/](governance/README.md) | Rules, priorities, working process, who decides | What are the rules? |
| [how-to/](how-to/README.md) | Steps for one specific task | How do I do X? |
| [learning/](learning/README.md) | A short Learning Note per step | What did we learn building this? |
| [progress/](progress/README.md) | Plan, phases, status, exit evidence | Where are we? |
| [reference/](reference/README.md) | API, schema, configuration, commands | What exactly is X? |
| [security/](security/README.md) | Threat model, security reviews, data classification | What can go wrong and what do we do about it? |
| [tutorials/](tutorials/README.md) | Guided lessons for a newcomer | How do I get started? |

Every file, with its title and what links to it: [MAP.md](MAP.md) (generated by `python3 scripts/docs_audit.py --map`).

Also: [verification-backlog.md](verification-backlog.md) (claims not yet verified), [glossary.md](glossary.md) (terms), and in the repository root `README.md`, `CHANGELOG.md` and `SECURITY.md`.

Tutorials, how-to guides, reference and explanation follow Diátaxis (https://diataxis.fr/). Keep the four kinds apart: a how-to does not teach, a reference does not argue.
