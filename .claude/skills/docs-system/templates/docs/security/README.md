# Security

- [threat-model.md](threat-model.md): what can go wrong and what we do about it. Update it in the same change as anything that alters data flows, trust boundaries, storage, identity or authorization.
- Security reviews and checklists go here, one file each.
- If the project stores personal or sensitive data, add `data-classification.md` (what classes of data exist, where each may go, how long it is kept).

How to report a vulnerability: `SECURITY.md` in the repository root.
